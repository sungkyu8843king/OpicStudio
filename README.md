# 트립메이트 – 단체 여행 일정 관리

단체 여행의 일정·지도·경비·맛집을 한 곳에서 관리하는 웹/앱 솔루션입니다.

## 주요 기능

### 👥 그룹 관리
- 그룹 생성 후 6자리 초대 코드 발급
- 카카오톡 공유 / 링크 복사로 멤버 초대
- 멤버 목록, 가구 수, 여행 기간 설정

### 📅 일정 계획
- 날짜별 타임라인으로 장소 추가
- 장소 유형: 관광지 · 숙소 · 식당 · 카페 · 교통 · 쇼핑
- 카카오맵 / 네이버지도 / T맵 딥링크 연동
- 장소명 검색 → 자동 좌표 매핑

### 🗺️ 지도 (Leaflet + OpenStreetMap)
- 일정 장소 전체 마커 표시
- 방문 순서 경로(polyline) 시각화
- 멤버 위치 시뮬레이션 표시
- 내 현재 위치(GPS) 트래킹
- 레이어 전환: 전체 / 장소 / 멤버 / 경로
- 카카오맵 · 네이버지도 · T맵으로 바로 열기

### 💰 경비 정산
- 영수증 사진 첨부 지원
- 카테고리: 식비 · 교통 · 숙소 · 액티비티 · 쇼핑 · 기타
- **1인당 / 가구당** 자동 분배 계산
- 결제자 기록, 날짜 및 메모 관리

### 🍽️ 맛집·카페 추천
- 현재 위치 기반 주변 음식점 소개
- 카테고리 필터: 한식 · 카페 · 양식 · 일식 · 중식 · 분식
- 별점 · 거리 · 영업 상태 표시
- 맛집을 일정에 바로 추가

## 실행 방법

`index.html` 파일을 브라우저에서 열거나 GitHub Pages로 배포합니다.

```bash
# 로컬 서버 실행 (선택)
python3 -m http.server 8080
# → http://localhost:8080
```

## 지도 앱 연동

장소 마커 클릭 → 팝업에서 카카오맵 · 네이버지도 · T맵 버튼으로 바로 이동합니다.  
모바일에서는 앱 딥링크, 데스크톱에서는 웹 URL로 자동 분기됩니다.

## 향후 개발 (실서비스)

| 항목 | 설명 |
|------|------|
| 백엔드 API | 그룹 데이터 공유 / 실시간 위치 |
| Kakao SDK | 카카오 로그인 + 실제 톡 공유 |
| 장소 검색 API | 카카오·네이버 로컬 API 연동 |
| 푸시 알림 | 멤버 도착 알림, 일정 리마인더 |
| PWA | 오프라인 지원, 홈 화면 추가 |
