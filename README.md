# OPIc Studio

오픽을 처음 공부하는 사람도 왕초보 문장부터 IM 수준 답변 구조까지 연습할 수 있는 정적 웹사이트입니다. 기출형 질문, 한국어 해석, 쉬운 답변, IM 목표 답변, 말하기 블록, 타이머, 녹음, 표현 은행을 제공합니다.

## 주요 기능

- 학습 현황 대시보드, 스트릭, IM 준비도 표시
- 즐겨찾기, 완료 표시, 오늘의 체크리스트 저장
- 왕초보 답변, IM 목표 답변, 말하기 블록 전환
- 내 답변 조립기와 답변 복사
- 5문항 미니 모의시험
- IM 셀프채점 루브릭
- 브라우저 녹음과 피드백 메모

## 실행 방법

`index.html` 파일을 브라우저에서 열거나 GitHub Pages로 배포해 사용할 수 있습니다.

## GitHub Pages 배포

1. GitHub 저장소의 `Settings > Pages`로 이동합니다.
2. `Deploy from a branch`를 선택합니다.
3. Branch를 `main`, folder를 `/root`로 지정합니다.
4. 저장 후 표시되는 Pages URL로 접속합니다.
